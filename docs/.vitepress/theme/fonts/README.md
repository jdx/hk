These faces set sea shanty mode's type (see ../shanty-mode.css). Each is
declared for every page, but a browser downloads a face only when text uses
it, and only the mode's rules do, so the plain site never fetches them.

IM Fell English (roman and italic) and IM Fell English SC are Igino Marini's
digitizations of the Fell types, cut in the 1670s. They set the mode's
headings, labels and small capitals. The files are the upstream fonts
compressed to WOFF2 and otherwise unchanged: the fonts reserve their names,
and the SIL Open Font License treats a subset as a modified version that
would have to be renamed.

Source: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/imfellenglish)
and [IM Fell English SC](https://github.com/google/fonts/tree/main/ofl/imfellenglishsc)
License: SIL Open Font License 1.1, included in IMFell-OFL.txt.

Libre Caslon Text (roman and italic, weights 400 to 700) sets the mode's
reading text. The files are the upstream variable fonts subset to Google
Fonts' Latin range and compressed to WOFF2; the font reserves no names.

Source: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/librecaslontext)
License: SIL Open Font License 1.1, included in LibreCaslonText-OFL.txt.
