Space Grotesk is bundled for deterministic social image generation without
system fonts or network access during the build.

Liberation Mono (Regular and Bold, version 2.1.5) is bundled so the showreel
draws its terminal and code text the same on every machine that renders it.

Source: [Liberation Fonts](https://github.com/liberationfonts/liberation-fonts)
